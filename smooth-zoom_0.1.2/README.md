# Smooth Zoom

A Factorio mod that makes camera zooming smoother and more comfortable.

Instead of changing the zoom instantly when using the mouse wheel, **Smooth Zoom** smoothly moves the camera toward the target zoom level.

## ✨ Features

* Smooth camera zoom in and out
* Adjustable zoom step
* Adjustable zoom speed
* Adjustable zoom inertia
* Works with the normal mouse wheel controls
* Keeps the standard Factorio zoom limits

## ⚙️ Default Settings

| Setting    | Default |
| ---------- | ------: |
| Zoom Step  |     20% |
| Zoom Speed |     20% |
| Inertia    |     20% |

These values can be changed in the mod settings.

## 🎮 Compatibility

* Factorio **2.0**
* Factorio **2.1**

## 📦 Installation

The easiest way to install the mod is through the Factorio Mod Portal:

**[Smooth Zoom — Factorio Mod Portal](https://mods.factorio.com/mod/smooth-zoom)**

You can also download a release manually and place it in your Factorio `mods` folder.
